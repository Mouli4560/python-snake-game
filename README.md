# python-snake-game
A classic Snake game built with Python and Pygame.

This project was developed as a hands-on exercise to apply Python fundamentals to game development.

# 🎮 Features

* Classic snake movement and food collection
* Collision detection (walls and self-collision)
*Score tracking and persistent high score
*Multiple difficulty levels
*Start menu and game-over screen
*Pause and resume functionality
*Sound effects
*Grid-based visual design

# 🕹️ Controls

|Key|Action|
|--|--|
|Arrow Keys|Move the snake|
|SPACE|Pause / Resume|
|ENTER|Start the game|
|R|Restart after game over|

# ⚙️ Installation

1. Install Python.
2. Clone or download this repository.
3. Install the required library:
   `pip install pygame`
4. Make sure eat.wav and crash.wav are in the same directory as main.py.
